# 课程模块分配与状态追踪

本表用于多人并行开发时记录模块责任与首个交付物。每个模块第一阶段建议限制为 3–5 个核心知识点，并先完成设计审核再实现。

使用说明：

- `First Deliverable` 建议写“知识点与题目设计包”或“首个可测试 Mini Unit PR”，避免写成笼统的“完成模块”。
- `Design Review` 通过前，不将候选题目直接加入 production template registry。
- `Completed` 表示 PR 已合并、测试通过且课程内容审核记录完整，不等同于对学习效果的研究结论。
