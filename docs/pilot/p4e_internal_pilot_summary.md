### 重复主题

- 来源点击或预览：4 处开放反馈提及。
- 知识图谱导航或详情定位：4 处开放反馈提及。
- 诊断覆盖、题量或题干可读性：重复出现，且诊断相关性均值未达到 QA/反馈清晰度水平。
- 在 5 份非空“最有帮助”回答中，审核诊断相关表述出现最多（3 份）；这只是主题计数，不代表总体偏好排序。

## Interpretation

- 核心演示链路可以走通，且 QA 清晰度、诊断反馈和知识图谱帮助度处于较高水平。
- 导航自然度是八项评分中的最低项；学习记录信任也低于 QA 清晰度和诊断反馈清晰度。这是下一阶段 UX 与测量可信度的优先信号，不是对 6 人样本作显著性推断。
- reviewed diagnostics 的安全边界仍合理：当前不足应通过更多人工审核模板与课程证据解决，而不能放宽自动证据写入。

## Recommended next action

1. 图谱返回已定位到实际知识点选择区域；课件 citation 预览仍作为下一阶段的低风险 UX 原型，前提是先解决远程材料可用性与授权边界。
2. 以课程证据、人工审核和 acceptance tests 扩充验证题覆盖，而不是让 LLM 开放题直接授予 mastery。
3. 单独设计 Pilot access 的短时会话改进；不把访问码写入 URL、localStorage 或长期明文 cookie。
4. 将跨课程、外部题库和 MCP 列入 Course Package / 后续版本规划，不在 Search Algorithms 夏季 MVP 中实现。
