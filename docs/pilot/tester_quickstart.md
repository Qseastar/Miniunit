# 内测者快速开始

## 启动

受邀测试时，由负责人或本地启动命令显式设置 `INTROAI_PILOT_MODE=1`。页面会多出“内测任务与反馈”标签；未设置时看不到该标签是正常行为。请保留浏览器地址栏中的 learner URL，以便在任务 5 中用同一链接验证本地学习状态恢复。

负责人会分别发送基础 URL 和内测访问码。P4d 远程测试中的 HTTPS URL 是临时地址，负责人终端关闭后会失效。访问码只在当前浏览器 session 中使用，不要把访问码附在 URL、反馈文件或截图中，也不要把自己的 learner URL 分享给其他测试者。首次打开页面时先输入访问码；访问失败只会显示通用提示。访问码不是账号密码，内测结束后负责人会停止进程。

负责人使用 `scripts/remote_pilot_ctl.sh` 管理远程实例；Quick Tunnel 重启后 URL 可能变化，但同一轮访问码保持不变。测试者不需要接触 PID、日志或进程命令。

## 操作

1. 依次完成页面列出的六项任务，并按实际完成情况勾选。
2. 在“结构化反馈”中为八项体验指标选择 1–5 分。`1` 表示很差或完全不同意，`5` 表示很好或完全同意。
3. 可选填写最有帮助之处、最困惑之处、遇到的错误和改进建议。系统会自动显示匿名测试编号，无需填写任何身份信息。
4. 页面短暂断开时先等待，再刷新；不要与其他人共享同一个浏览器会话。
5. 点击“生成反馈下载”；如需确认内容，可展开页面中的预览。
6. 点击“下载本次内测反馈”，再将下载文件通过负责人约定的组内方式发送。

## 请勿填写

不要填写姓名、学号、手机号、邮箱、真实账号、完整课程问题、完整回答或其他敏感个人信息。不要填写或发送 API Key、`.env`、案件信息或本地数据库。匿名编号由系统自动生成，仅用于区分反馈文件，不关联学习档案或身份。如发现严重错误，请记录可复现步骤；截图应避开密钥、地址栏中的私人信息和私人聊天内容。

## 学习记录说明

自由问答、知识图谱浏览和内测反馈本身不会更新学习记录。只有通过人工审核的确定性验证题，才会按现有规则更新本地学习状态。重复同一验证题的复习练习不会新增独立掌握度证据。
