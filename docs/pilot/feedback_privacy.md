# 内测反馈隐私说明

导出文件只包含：schema 版本、内测标识、系统自动生成的非身份化测试编号、已勾选任务 ID、八项 1–5 评分、主动填写的开放反馈和生成时间。历史下载文件中的空编号仍可由离线汇总工具读取。

导出文件不包含：learner UUID、学习档案、mastery、recommendation、evidence、exposure、课程问题、学生回答、prompt、chunk、API Key、Authorization、数据库路径、IP、user agent 或完整内部状态。

内测页面只生成浏览器下载内容，不上传到服务器，不写入 SQLite，不读取或修改学习记录。刷新或清空学习档案不会自动删除尚未下载的浏览器表单内容；测试者应自行下载或使用“重置内测反馈表”清空。

开放文本由测试者主动输入，仍可能含有敏感内容。因此请勿填写个人信息或完整学习内容；负责人收到文件后应仅在项目约定的受控位置保存和处理，在汇总和修复完成后按团队约定删除原始下载文件。匿名编号仅用于区分反馈，不应被解释为真实身份。
