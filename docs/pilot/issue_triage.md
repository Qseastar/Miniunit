# 内测问题分级与处理

使用 `issue_triage_template.csv` 记录问题。`anonymous_tester_code` 可为空，不填写姓名或 learner UUID。

| 等级 | 定义 | 决策 |
| --- | --- | --- |
| P0 | secret 泄漏、学习状态串档、清空错误档案、重复题错误提高正式 mastery、伪造 evidence | 立即停止内测 |
| P1 | QA 完全不可用、审核诊断无法开始或提交、状态无法保存恢复、反馈无法生成 | 组会前必须修复 |
| P2 | 文案误导、跳转失效、图谱难懂、题面不自然、重试困惑 | 按频率和影响排序 |
| P3 | 间距、颜色、按钮偏好和未来建议 | 进入 backlog，不阻塞黄金模板封存 |

同一问题先按复现步骤和影响去重，再统计出现人数。P0/P1 以安全和核心流程优先，不用更多反馈掩盖问题。
